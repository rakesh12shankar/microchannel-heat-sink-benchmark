# Publication package

Public repository: https://github.com/rakesh12shankar/microchannel-heat-sink-benchmark

Organization follows jt-microsystem-cooling: root run/model/build scripts, config/, data/, docs/, results/, dependency files and an upload manifest. Saved Fluent binaries are distributed as the v1.0.0 release asset rather than in Git history.

UPLOAD_MANIFEST.json records the SHA256 and byte count of each public file except itself. The release archive has its own CHECKSUMS.json for original case/data pairs and a separate SHA256SUMS.txt for the download.

Publisher files, full-text extracts, development transcripts, local Python environments, SolidWorks lock files, license configuration, and unrelated personal workspace data are excluded. No open-source license has been selected, matching the companion repository's current reuse statement.
